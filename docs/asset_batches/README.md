# PNG batch evidence

Эта папка содержит только текстовые evidence-файлы партий. Реальные PNG лежат отдельными файлами в соответствующих `docs/mockups/<stage>/` каталогах.

Именование: `docs/asset_batches/<stage>/batch-001.json`.

Каждый evidence-файл обязан содержать `PLACED` только после проверки фактических GitHub paths/blobs, размера и SHA-256 каждого PNG.

Размер партии: ровно 40 файлов, если осталось не меньше 40; последняя партия содержит весь остаток, если его меньше 40. Один агентский запуск не переходит к следующей партии.

ZIP, GitHub Release assets, Base64 в текстовых файлах, data URL и визуальные заменители запрещены.
