# Stage 14 — Enemy Death

Status: PLANNED.

Цель: смерть врага должна оставлять материальное последствие, а не просто эффект «лопнул и исчез».

Обязательные материалы для десяти enemy_id:

- hit, stagger, death и короткий readable timing;
- corpse sprite или фрагмент тела;
- конечности, кости, ткань, обломки, чернила/кровь/пыль согласно типу врага;
- пятно или локальный след на поверхности;
- отдельный XP-drop, визуально не смешанный с останками;
- low-detail вариант и cluster/decal-вариант для поздней волны;
- контрольные кадры/preview на 0/5/10/15/20 минутах.

Целевой результат: к 20-й минуте поле визуально ощущается устланным трупами, конечностями и следами боя. Останки не имеют collision, не блокируют проход, не участвуют в pathfinding и не уничтожают XP. При достижении лимита они сворачиваются в кучки/decals, сохраняя ощущение накопленного боя.

Критерий готовности: у каждого врага есть уникальный aftermath, останки читаются на мобильном экране, XP остаётся заметным, а плотный слой не нарушает performance budget.
