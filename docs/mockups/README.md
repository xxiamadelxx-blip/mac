# Mockups

Здесь хранятся визуальные мокапы игры. Индекс и статусы находятся в `../MOCKUP_INDEX.md`.

Каждый этап получает отдельную папку. Preview, описание поведения и файл привязки должны иметь одинаковый идентификатор и версию.

Нельзя отмечать этап DONE, если создана только папка или текстовое намерение без фактического мокапа и проверки.

## Активная визуальная итерация v02

Этапы 1–2 получили единый soft-tonal candidate pack: [меню v02](./01-menu/README.md) и [арена v02](./02-arena/README.md). Новые composites и review-плитки находятся в соответствующих папках; v01 сохранён для истории и сравнения. Статус обоих этапов — **IN PROGRESS / USER REVIEW**, пока не пройдены утверждение и runtime/Android-проверки.
