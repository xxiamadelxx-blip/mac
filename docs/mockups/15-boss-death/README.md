# Stage 15 — Boss Death

Status: PLANNED.

Цель: смерть босса должна менять состояние арены и ощущаться наградой.

Обязательные материалы для четырёх boss_id:

- потеря брони, переход фазы и финальное поражение;
- распад/обрушение тела и несколько крупных читаемых фрагментов;
- post-death environmental beat: треснувшая печать, погасшие фонари, затопленный проход или другой безопасный след;
- отдельный XP-drop, Boss Essence и визуал награды;
- переход к экрану результата без блокировки управления;
- low-detail/cleanup состояние, совместимое с накопленными останками обычных врагов.

Критерий готовности: смерть босса не перекрывает XP, не блокирует движение, корректно переживает паузу/сворачивание и не ломает визуальный слой арены.
