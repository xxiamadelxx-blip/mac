# Stage 09 — XP

Status: PLANNED.

Цель: сделать опыт понятным как отдельные светящиеся XP-точки/кристаллы, знакомые по Vampire Survivors, но с оригинальным визуалом Moonveil.

Обязательные материалы:

- шесть градаций: малая искра 1 XP, осколок 5, кристалл 15, большой кристалл 40, ядро элиты 80, ядро босса 250;
- idle-пульсация и анимация появления в точке смерти;
- магнитная дуга к героине, всплеск шкалы XP и звук подбора;
- читаемая форма/размер/ореол/звук для разных ценностей, а не только цвет;
- пример слоя XP поверх трупов, конечностей и следов на арене;
- пример объединения мелких предметов при переполнении без потери суммарного XP;
- состояния шкалы до подбора, во время магнита, после подбора и при повышении уровня.

Критерий готовности: XP-предметы легко найти и подобрать среди накопленных останков, они не проходят через стены, не закрывают телеграфы и не исчезают при pooling/кластеризации. Числа и кривая XP сверяются с BALANCE_ECONOMY_SPEC.md.

Фактические preview и evidence добавляются сюда после начала этапа. Этот README сам по себе не означает DONE.
