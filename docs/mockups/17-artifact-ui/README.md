Состояние этапа: PLANNED (запланирован).

Фактические результаты этапа, предварительный просмотр и подтверждающие материалы добавляются сюда после начала этапа. Одна папка или этот файл сами по себе не означают завершение этапа.

## Контентный бриф версия 01 — предложение артефакта и состояния Кодекса

Это текстовый бриф интерфейса и контента. Он не создаёт мокап, иконку, иллюстрацию Кодекса или производственный ресурс.

| Поле | Значение |
|---|---|
| состояние контента | PROPOSAL |
| техническая проверка | NOT_RUN |
| художественное утверждение | PENDING |
| подключение к игре | NOT_PROMOTED |

### Поток предложения и состояний

1. Событие-источник создаёт предложение из трёх разных карточек.
2. Игрок изучает обещание карточки, событие, границу цели и текущее состояние.
3. Игрок выбирает одну карточку; выбранное состояние видно до подтверждения или закрытия.
4. Артефакт добавляется в отдельный набор забега; ячейки оружия и пассивок не меняются.
5. Повтор, улучшение или резервная награда показываются явно; точная ценность и правило обновления — PENDING_BALANCE/PENDING_PRODUCT.
6. Запись Кодекса может иметь состояние открыта/не открыта, но область сохранения FIRST_CLEAR_REWARD — PENDING_ARCHITECTURE.

### Обязательные состояния интерфейса

| Состояние | Поведение контента |
|---|---|
| OFFER_OPEN | три карточки, источник, краткое событие и цель, указание «выбрать одну» |
| CARD_FOCUSED | раскрытое обещание, наблюдаемый результат, текущий накопленный эффект и предупреждение о синергии |
| CARD_SELECTED | явное выбранное состояние, подтверждение или завершение; другие карточки закрыты |
| OWNED_DUPLICATE | понятное сообщение о повторе, улучшении или резервной награде; новой ячейки нет |
| SOURCE_LOCKED | объяснение требования ELITE_PACK или FIRST_CLEAR_REWARD |
| CODEX_DISCOVERED | полный текст контента и семантический ключ эффекта |
| CODEX_UNDISCOVERED | силуэт и имя принадлежат агенту визуального оформления; скрытые механики не раскрываются случайно |
| OFFER_RESOLVED | результат и активная метка артефакта возвращаются в игровой интерфейс |
| ERROR_OR_EMPTY | понятное сообщение о резервном результате; пустых карточек нет |

### Договор отображения семантических ключей

Семантический ключ можно показывать только как внутреннее отладочное подтверждение; игрок видит обещание контента. Канонические ключи:
aura.drop_route_compass, trigger.critical_echo, trigger.elite_ember_path, modifier.control_bloom, trigger.guard_resonance, trigger.overheal_ward, target.boss_phase_window, modifier.elite_polarity, aura.drop_tide_path, target.threat_telegraph.

Все коэффициенты, перезарядка, длительность, радиус, редкость, стоимость обновления и сохранение — PENDING_BALANCE/PENDING_ARCHITECTURE/PENDING_PRODUCT.
