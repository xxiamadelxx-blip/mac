## Визуальный контракт

Арена содержит большой связанный мир, а не один узкий экран: минимум 1560×2532 world units, то есть 4 экрана по ширине и 3 по высоте. В центре — открытое поле для кругового движения вокруг волн; вода, мосты, камни, корни, фонари и лотосы находятся в основном по краям и образуют ориентиры, а не стены. Текущий кадр камеры должен оставлять примерно 65–75% пространства проходимым.

`STAGE02_ARENA_ART_v01.png` не удалён, но теперь обозначен как сектор старого направления. Активный визуальный кадр для игровой камеры — `STAGE02_ARENA_OPEN_FIELD_ART_v02.png`. Камера следует за героиней, а враги появляются за пределами видимой рамки во внешнем кольце.

После смертей добавляется материальный след: тела, конечности, кости, ткань и чернильные пятна. Останки не имеют collision, не блокируют путь и не смешиваются с XP.

## Runtime-preview

Сцена прогоняет состояния 0→20 минут за 60 секунд. В ней видны:

1. циклическая рябь и рябь от касания;
2. колыхание растений;
3. дрейфующие частицы воздуха;
4. усиление частиц затмения после 10-й минуты;
5. постепенное накопление останков.

Кнопка `‹ МЕНЮ` написана по-русски и возвращает в меню. Это технический preview, а не финальный HUD.
