# Проверка этапа 02 — арена v01

Статус проверки: **REVIEW**.

## Проверено статически

- все preview имеют размер 390×844;
- макро-схема имеет размер мира 1560×2532 и показывает 4×3 мобильных окна;
- активный кадр игровой камеры показывает широкое открытое поле, а не один центральный коридор;
- старый узкий арт сохранён только как сектор и не используется как единственный масштаб карты;
- базовый арт, атмосферный слой и слой останков существуют отдельно;
- есть контрольные композиты 0/5/10/15/20 минут;
- слой останков не закрывает открытое игровое поле полностью;
- XP не объединён с останками и оставлен отдельным будущим слоем;
- JSON-карта слоёв содержит viewport, зоны, реакции и ограничения плотности;
- сцена и скрипт используют только `res://`-пути проекта;
- видимый текст в preview отсутствует, служебная кнопка Godot написана по-русски.

## Runtime evidence

Сцена `scenes/arena/arena.tscn` подключает `scripts/arena/arena_controller.gd` и:

- автоматически прогоняет 0→20 минут за 60 секунд в preview-режиме;
- анимирует рябь, растения, пыльцу и частицы затмения;
- добавляет останки по мере роста игрового времени;
- принимает касание/клик по арене и показывает локальную рябь;
- содержит кнопку `‹ МЕНЮ` для возврата в меню.

## Ограничение среды

Godot 4.x в текущей среде отсутствует. Поэтому выполнена статическая проверка путей, структуры сцены, данных и размеров PNG; локальный запуск Godot и APK-прогон остаются непроверенными и не являются основанием для `DONE`.

## Критерии перехода к DONE

1. Открыть сцену в Godot 4.x и подтвердить отсутствие ошибок загрузки.
2. Пройти весь 60-секундный preview и увидеть пять состояний плотности останков.
3. Проверить касанием рябь минимум в трёх местах и убедиться, что она не блокирует ввод.
4. Убедиться, что будущие места HUD свободны, а открытая зона позволяет обойти волну по дуге.
5. После интеграции с реальным героем, врагами и XP повторить проверку на Android-устройстве.
